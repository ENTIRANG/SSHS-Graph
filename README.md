## 센서 배치

온도 실험 두 건은 같은 3채널을 쓴다. **D18은 양쪽 모두 물(대조군)** 이다.

| 채널 | 실험 1 | 실험 2 |
|---|---|---|
| D18 | 물 (대조군) | 물 (대조군) |
| D16 | 아세톤 | 염화칼슘 (발열) |
| D20 | 에탄올 | 질산암모늄 (흡열) |

내려가는 중이라 최저점은 데이터 바깥에 있다.

## 데이터를 읽을 때 걸리는 점

1. **실험 2의 물이 114행 내내 정확히 26.0** — 분해능이 0.0625 °C(1/16)인데 2분간 한 번도
   흔들리지 않았다. 같은 채널이 실험 1에서는 같은 시간에 0.75 °C 내려갔다. 센서 미연결이나
   기록 고정을 의심할 만하다.
2. **세제는 아직 수렴하지 않았다** — 28초 내내 6.47에서 7.41로 한 방향으로만 올라간다.
   평균·중앙값·절사평균이 서로 어긋나는 것이 그 신호다. 측정 시간을 늘려 다시 재는 편이 낫다.
3. **물이 pH 7.96** — 중성이어야 할 물이 8 가까이 나온다. 전극 보정 문제라면 나머지 5개도
   같은 방향으로 치우쳐 있다. 시료 간 상대 순서는 쓸 수 있지만 절대값은 보정 후 재측정이 필요하다.

## 원자료 형식

```
time,temp(D16),temp(D18),temp(D20)     # 실험 1·2 — 약 1 Hz, 일부 초 결측
00:00:02,26.625,26.0,26.4375

time,pH(A0)                            # 실험 3 — 초당 2~3회, 같은 초에 여러 행
00:00:01,8.204559
```

시각은 기록 시작부터의 경과 시간이다. 결측 초는 채우지 않고 실제 기록 시각 그대로 둔다.
